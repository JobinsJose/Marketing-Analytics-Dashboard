# Marketing Campaign Analytics Dashboard

## About the Project
This project explores customer data to understand marketing campaign performance, customer purchasing behavior, and factors influencing campaign responses.

## Technologies
- SQL (MySQL)
- Power BI
- DAX
- Power Query

## What I Did
- Prepared and transformed customer data using SQL.
- Analyzed campaign responses and customer purchasing patterns.
- Created KPIs to monitor campaign performance.
- Built interactive Power BI dashboards to explore customer demographics and campaign effectiveness.
- Used RFM analysis to group customers based on purchasing behavior.

## Skills
SQL, data preparation, exploratory data analysis, customer segmentation, KPI reporting, and Power BI visualization.
